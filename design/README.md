# Identidade visual do FichaPro

O símbolo combina duas peças em forma de F. O recorte em degrau reaparece em ícones, molduras de foto e na ação principal, conforme a referência aprovada.

## Paleta

| Cor | Código | Uso |
|---|---|---|
| Azul-noite | `#10243B` | Marca, títulos, texto e ícones |
| Azul royal | `#2457D6` | Ações principais e ícone do app |
| Branco frio | `#F4F7FB` | Fundo e versão clara do símbolo sobre superfícies escuras |
| Ciano | `#A9E8EF` | Fundo de destaques e estados com texto azul-noite |

## Uso da marca

Use `logo-claro.svg` em superfícies claras e `logo-escuro.svg` em superfícies escuras. Use o símbolo isolado quando o espaço for reduzido. O letreiro do logo está em curvas. A proposta tipográfica para a interface é uma sans-serif geométrica com boa leitura em formulários. A fonte da interface será definida na etapa de telas.

Os ícones de interface seguem uma grade 24 × 24 com traços arredondados. Use rótulos de texto nas ações principais e nomes acessíveis nos botões que exibem somente um ícone. O ícone de QR é um pictograma de interface. Os códigos de validação dos PDFs serão gerados individualmente.

## Aplicativos e web

| Arquivo | Uso |
|---|---|
| `icone-app.svg` | Versão quadrada com cantos arredondados para prévias e materiais |
| `icone-ios.svg` | Matriz opaca de 1024 unidades para exportação do ícone iOS |
| `icone-android-fundo.svg` e `icone-android-frente.svg` | Matrizes separadas para o ícone adaptativo do Android |
| `icone-web-maskable.svg` | Matriz para gerar ícones instaláveis na web |

As matrizes SVG serão convertidas para os recursos de cada plataforma durante a integração. A próxima etapa de design cobre as demais telas, o PDF e a página de validação.
